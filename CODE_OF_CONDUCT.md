# Code de conduite

Ce projet est fait par et pour des gens qui appellent des entreprises toute la journée : on se parle ici comme on voudrait qu'un
prospect nous parle.

## Ce qu'on attend

- Du respect et de la bonne foi dans les issues, les discussions, les revues et les commits : on critique le code, jamais la personne.
- Des échanges utiles : un ticket précis, une réponse qui aide, un désaccord argumenté.
- La bienvenue aux débutants : il n'y a pas de question « bête » ; on répond, ou on renvoie vers la bonne page de la documentation.
- Aucune donnée réelle d'une personne ou d'une entreprise prospectée, nulle part. C'est une règle de conduite autant qu'une règle
  technique du dépôt.

## Ce qui n'a pas sa place

Les insultes, le harcèlement, les remarques sur l'origine, le genre, l'orientation, la religion, le handicap ou l'apparence, les
menaces, la publication d'informations privées, le démarchage commercial dans les espaces du projet.

## En cas de problème

Signale-le en privé plutôt qu'en public : par le signalement de contenu de GitHub (menu « … » d'un message › « Report content ») pour
un abus manifeste, ou en écrivant au mainteneur par le moyen indiqué sur son profil GitHub. Les mainteneurs peuvent masquer ou
supprimer un message, fermer une issue ou une discussion, et bloquer une personne qui ne respecte pas ces règles.
